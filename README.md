## 📌 How News Is Selected

Each news entry should include:

- **Headline:** What happened?
- **Summary:** What are the key details?
- **Impact:** Why does it matter?
- **Source:** Where was it originally reported?
- **Date:** When was it published?

News should be verified against reliable sources before publication.
